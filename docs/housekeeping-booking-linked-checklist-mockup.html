Flip the booking status below to see the same room's list change on its own.
How real turnover-management tools do this (Turno, Breezeway, Properly — all built for exactly this problem):
  • The booking calendar creates the day's cleaning task automatically — no manual daily assignment for the standard case.
  • A guest departing gets the full turnover clean; a guest staying (stayover) gets a lighter "refresh" list — trash, towels, tidy — not the full checklist.
  • The heaviest tasks (deep-clean items) run on their own slower cadence, not every single turnover — this is already how NIVA's weekly/monthly cadence works.
  • The manager can always override a specific day — the automatic list is a smart default, never a hard rule.
